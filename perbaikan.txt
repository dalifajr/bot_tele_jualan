1. [SELESAI] Akar Masalah 1: Error 401 "Signature Tidak Valid"
   - Analisis: env('LISTENER_SHARED_SECRET') bernilai null di controller saat config:cache aktif di VPS,
     serta config services.php belum didaftarkan sehingga fallback selalu ke 'change-me'.
   - Solusi: 
     a) Daftarkan config listener di web/config/services.php.
     b) Multi-tier secret discovery + sanitasi quotes/whitespace di PaymentListenerController.php.
     c) Buat UI modern di Dashboard Web Admin (Konfigurasi Sistem -> Payment & QRIS) untuk melihat & mengubah secret key.
   - Hasil Pengujian: Tests\Feature\PaymentListenerTest PASS 100% (3 passed, 5 assertions).
